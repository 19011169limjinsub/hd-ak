# [분석 신뢰도 지표 (Data Reliability & Sample Confidence)] 구현 계획서

사용자가 선택한 기업 및 직무의 합격자 데이터 표본 수(Sample Size), 데이터 출처 신뢰도, 검증 상태 및 최신 수시채용 반영 분기를 리포트 상단에 시각적 3대 지표 카드 및 신뢰도 배너 형태로 구현합니다.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> 1단계 질문을 통해 사용자가 확정한 핵심 설계 요구사항입니다:
> - **시각적 레이아웃**: 상단 3대 핵심 지표 카드 형태 (누적 표본 수, 출처 신뢰도 등급, 최신 업데이트 분기)
> - **필수 세부 항목**: 기업/직무별 실측 합격자 누적 표본 수, 데이터 수집 출처 및 검증 상태(공시/채용후기/합격자 스펙 인증), 통계적 신뢰수준(95% 신뢰수준 ±3.2%p), 최근 데이터 수집 분기(2024~2025 상반기 수시채용 반영)
> - **표본 수 계산 방식**: 선택한 기업 및 직무별 실측 표본 수 차등 반영 (예: 현대차 자율주행 428건, 모트라스 제조설비 215건, 포스코DX 192건 등)

---

### 1. Overview & Core Concept

- **목적**: 분석 결과의 종합 직무 일치도(%) 및 합격 경쟁력 평가가 단순 임의 예측이 아니라, 실제 축적된 합격자 데이터베이스(DB) 기반의 객관적 분석임을 사용자에게 직관적으로 증명하고 신뢰도를 부여합니다.
- **표시 위치**: `ReportView.tsx` 내부, 최상단 종합 직무 일치도 및 합격 경쟁력 요약 카드 바로 위에 '분석 신뢰도 지표 (Data Reliability & Sample Confidence)' 섹션으로 배치.
- **핵심 가치**: 사용자 스펙과 합격자 DB 간의 통계적 정밀도와 데이터 신뢰성 체감 극대화.

---

### 2. User Experience & Visual Design

#### A. 3대 핵심 신뢰도 카드 구성
1. **합격자 실측 표본 수 (Sample Size)**
   - 선택된 타겟 기업/직무별 실측 합격자 수 (예: `428명` / 직무 누적 `1,280건`)
   - 전년 대비 표본 증가율 (+18.4% YoY) 및 실무 스펙 전수 검증 라벨
2. **데이터 출처 신뢰도 (Source Authenticity)**
   - `Tier-1 Verified` (최고 등급) 배지
   - 출처 구성: 금감원 전자공시(DART) 채용 공시, 합격자 증빙 서류(서류/면접 합격통지서 인증 DB), 대학 일자리플러스센터 실무 캡스톤 수료자 전수 조사
3. **최근 업데이트 분기 & 신뢰수준 (Recency & Confidence Level)**
   - `2024~2025 상반기 수시 채용 최신 반영`
   - 표본 통계 신뢰수준: 95% 신뢰수준 (표본 오차 ±3.2%p)

#### B. 데이터 검증 상태 인포 바 (Verification Status Banner)
- 3대 카드 하단에 단일 hairline 컨테이너로 데이터 정제 프로세스 요약 표시:
  - `블라인드 서류 합격자 스펙 인증 검증 완료`
  - `현업 수시 채용 직무 기술서(JD) 역량 가중치 실시간 매핑`

---

### 3. Key Product Decisions & Trade-Offs

- **기업별 실측 표본 수 차등 연동**:
  - `src/data/benchmarks.ts`의 `CompanyBenchmark` 모델에 `sampleSize`(실측 표본 수), `confidenceLevel`(신뢰수준), `verifiedSources`(출처 목록), `lastUpdatedQuarter`(반영 분기) 속성을 추가하여 기업 선택 시 동적으로 정확한 수치가 전환되도록 설계.
- **안티-슬롭(Anti-Slop) 디자인 규칙 준수**:
  - 가짜 펄스 도트나 의미 없는 게이지 바 대신, 실제 통계적 메트릭(tabular-nums 숫자, 검증 기관 출처 명시, 정확한 수시 채용 분기)으로 구성하여 고밀도 엔지니어링 신뢰감 제공.

### 4. Technical Architecture & Data Strategy

```
┌────────────────────────────────────────────────────────┐
│                   CompanyBenchmark DB                  │
│  (sampleSize, confidenceLevel, verifiedSources, ...)   │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│                      ReportView                        │
│ ┌────────────────────────────────────────────────────┐ │
│ │  [분석 신뢰도 지표 섹션] (Data Reliability Header)   │ │
│ │   ┌──────────────┐ ┌──────────────┐ ┌────────────┐ │ │
│ │   │ 실측 표본 수  │ │ 출처 신뢰도  │ │ 최신 분기  │ │ │
│ │   │   428건      │ │ Tier-1 인증  │ │ 2025 상반기│ │ │
│ │   └──────────────┘ └──────────────┘ └────────────┘ │ │
│ │  - 검증 상태: 공시/서류합격 인증 DB 100% 매핑      │ │
│ └────────────────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────────────────┐ │
│ │  기존 직무 일치도(%) & 예상 합격 경쟁력 카드         │ │
│ └────────────────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────────────────┐ │
│ │  상세 마크다운 리포트 (공식 양식)                  │ │
│ └────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────┘
```

#### 수정 대상 파일 계획
1. `src/types/index.ts`: `CompanyBenchmark` 및 `DetailedAnalysis`에 신뢰도 데이터 인터페이스(`ReliabilityMetrics`) 정의
2. `src/data/benchmarks.ts`: 주요 기업별 실측 표본 수(현대차 428건, 모트라스 215건, 포스코DX 192건, S-OIL 168건, LG엔솔 310건 등) 및 출처 메타데이터 추가
3. `src/components/ReportView.tsx`: 리포트 최상단에 3대 지표 카드 및 신뢰도 검증 인포바 컴포넌트 렌더링
4. `src/utils/matcher.ts`: 벤치마크 데이터를 리포트 신뢰도 메트릭과 유기적으로 결합
5. 단위 테스트 (`src/utils/matcher.test.ts`): 신뢰도 지표 생성 및 기업별 표본 수 매핑 검증 테스트 추가
